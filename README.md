# 🚗 FP Selection

Uma experiência digital criada para apresentar carros esportivos de alta performance através de uma interface moderna, imersiva e interativa.

O **FP Selection** é um projeto front-end focado em design, animações e experiência do usuário, desenvolvido a partir de uma ideia de showcase automotivo e posteriormente aprimorado com uma identidade visual própria.

## 🎯 Sobre o projeto

O objetivo do FP Selection é criar uma experiência visual para apresentação de veículos esportivos, colocando o carro como elemento principal da interface.

A navegação permite explorar diferentes modelos através das setas, indicadores de posição e, em dispositivos móveis, gestos de swipe.

O projeto também foi desenvolvido pensando em **responsividade, microinterações e experiência do usuário**.

## 🎨 Interface

O design foi desenvolvido com uma estética inspirada em **automóveis esportivos e marcas premium**.

- 🌌 Fundo escuro com gradientes
- 🔵 Iluminação em azul elétrico
- ✨ Efeitos de glow
- 🚗 Destaque visual para os veículos
- 🎞️ Animações de transição
- 🎯 Indicadores de navegação
